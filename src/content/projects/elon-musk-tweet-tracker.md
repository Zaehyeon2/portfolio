## 배경 및 목표

① 신규 서비스 [PredictGo](../predictgo/)를 준비하면서 글로벌 1위 예측 마켓 플랫폼인 [폴리마켓](https://polymarket.com/ko)의 시장 조사 및 벤치마킹 진행.
② 당시 폴리마켓 내에서 가장 주목받던 주제 중 하나인 '일론 머스크의 주간 트윗 개수 예측 베팅'을 분석하고 직접 참여.

→ 일론 머스크의 Twitter/X 게시 패턴을 실시간 히트맵으로 시각화하고 활동량을 예측하는 웹 대시보드를 개발하여 데이터 기반의 투자 전략 수립을 목표로 함.

## 역할

전 과정 주도 (1인 개발: 데이터 파이프라인 · 예측 알고리즘 · 프론트엔드 · 정적 배포)

## 주요 업무 및 성과

### ① 실시간 데이터 시각화 및 UI/UX 구현

- **데이터 파이프라인**: Polymarket X Tracker JSON API 소스를 직접 분석 및 연동하여, 일론 머스크의 실시간 Twitter/X 게시글 데이터를 안정적으로 fetch하는 파이프라인 구현.
- **시각화**: 요일별 × 시간대별(24H × 8D) 트윗 빈도를 직관적으로 인지할 수 있는 실시간 히트맵을 구현하고 현재 시간(ET 기준) 하이라이트 적용. 최근 4주 이동 평균(Moving Average)과의 듀얼 비교 뷰를 제공하고, 60초 자동 새로고침(Polling)으로 갱신.
- **활동 속도계**: 현재 시간당 트윗 속도를 4주 평균으로 나눈 비율을 5단계 게이지로 보여 주어, 지금 평소보다 활발한지 한눈에 판단하게 함.

### ② 활동량 예측(Prediction) 알고리즘 설계

- **Current Pace / End of Range**: 베팅 범위 종료 시점까지의 예상 총 트윗 수를 계산하는 알고리즘 구현.
- **Next 24h Prediction & Trend Indicator**: 4주간의 누적 활동 패턴 및 최근 가속도 가중치를 결합하여 향후 24시간 내 발생할 트윗 수 예측 모델을 적용하고, 활동 추세(상승/안정/하락)를 지표화.

### ③ 서버 없는 구조로 운영

- **정적 배포와 API 우회**: GitHub Pages 정적 배포라 서드파티 API를 CORS 프록시로 경유하고, API 실패 시 CSV 업로드로 대체하는 폴백을 두어 서버 없이 운영. 새로고침 시 404가 나지 않도록 SPA 폴백(404.html) 적용.
- **정산 주기 반영**: 폴리마켓 정산 주기에 맞춰 금-금·화-화 범위를 ET 정오 기준으로 계산해 베팅 범위와 같은 기준으로 집계.

## 결과

① 단순한 감이 아닌 데이터에 기반한 트레이딩 전략(Data-driven Betting)을 세울 수 있도록 돕는 실용적인 유틸리티 대시보드 완성.

## 회고

신규 예측 마켓 서비스를 준비하며 단순한 조사를 넘어, 실제 유저 입장에서 벤치마킹 사이트를 이용하고 필요한 기능을 직접 개발해 본 뜻깊은 프로젝트였다. 특히 AI 에이전트(Claude Code)를 개발 프로세스 전반에 적극 도입하여, Polymarket API 분석부터 이동 평균 및 가중치 트렌드를 결합한 24시간 예측 알고리즘까지 프론트엔드 단에 신속하게 구현할 수 있었다.

프로젝트 초기에는 빠른 검증을 위해 Vanilla JS로 프로토타입을 만들었으나, 결국 확장성을 위해 React 19와 TypeScript 아키텍처로 리팩토링하는 과정을 거쳤다. AI를 활용해 고속 개발을 진행할 계획이었다면, 초기 공수를 줄이려 하기보다 처음부터 확장성이 높은 최신 기술 스택(React+TS)을 선택하는 것이 장기적인 비용 측면에서 훨씬 효율적이라는 교훈을 얻었다.
