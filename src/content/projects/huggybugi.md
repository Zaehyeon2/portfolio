## 배경 및 목표

친구들과 메신저 대화보다 가볍게 "지금 뭐 하는지"를 주고받고 싶었으나, 기존 메신저는 대화창 중심이라 그런 신호를 주고받기 어려웠음.

→ 화면 아래 투명 오버레이에서 친구마다 픽셀 캐릭터가 걸어 다니며 접속·졸음·잠 상태와 말풍선을 보여 주는 데스크톱 앱을 직접 개발. 아이템 던지기 · 피하기 · 쓰다듬기 · 먹이 주기 같은 장난을 실시간으로 주고받고 캐릭터와 아이템은 친구가 직접 그려 올릴 수 있게 함. Mac·Windows 혼재 환경, 적은 운영 비용을 목표로 설계.

## 역할

전 과정 주도 (1인 풀스택 개발: 설계 · DB 스키마 · 서버 API · 실시간 프로토콜 · 데스크톱 앱 · 웹 · 배포 · 소개 페이지)

## 주요 업무 및 성과

### ① 투명 오버레이 위의 실시간 캐릭터 메신저

- 오버레이와 실시간: Electron 투명·클릭 통과 창에 canvas로 캐릭터를 그리고 게임·영상 같은 전체화면 앱이 뜨면 자동으로 비켜남. 던지기 속도는 화면 대비 비율로 보내 해상도가 달라도 궤적이 같음.
- 캐릭터와 콘텐츠: 먹으면 커지고 배부르면 응가하는 상태 순환과 밟기·하이파이브로 말 없이도 서로를 챙기게 함. 캐릭터·아이템은 D1 행 + R2 스프라이트로 정의해 앱에서 그려 올리면 바로 반영되고, 시즌 테마도 앱 배포 없이 켜고 끔.
- 폰과 직장인 도구: 데스크톱 대화 기록을 폰 브라우저에서 그대로 쓰게 하고(웹 푸시), 연봉 타이머·집중 타이머·3D 왁스 깨기(Three.js)처럼 일하다 잠깐 쓰는 도구를 더함.

### ② 공개에 맞춘 서버 이전과 보안

- Cloudflare 이전: 공개 전에 Supabase에서 Workers·D1·Durable Objects·R2로 옮김. 그룹마다 Durable Object 하나가 쓰기와 소켓 전달을 맡아 권한 검사와 실시간을 한곳에 모음. 계정은 비밀번호 해시째 옮겨 친구들이 그대로 로그인.
- 채팅 잠금: 말·사진·링크 카드·낙서 쪽지를 그룹 키(AES-GCM)로 잠가 보내고 그룹 키는 서버 공개 키(HPKE)로 봉해 전달. SSL 프록시에도 내용이 보이지 않음. 링크 미리보기는 서버가 대신 받고 리다이렉트마다 다시 검사해 SSRF를 차단.
- 계정과 결제: 이메일 인증, 구글 로그인(세션 대신 일회용 코드를 앱이 PKCE로 교환), 대입 횟수 제한, 신고를 갖춤. 칸 결제는 웹훅 본문을 믿지 않고 서버가 결제사에 다시 조회해 확정하며, 운영 대시보드는 Cloudflare Access 뒤에서 토큰을 한 번 더 검증.

### ③ 혼자서도 굴러가는 검증·배포·성능

- 두 앱을 띄워 CDP로 조작하는 e2e 241개 체크와 앱 테스트 644개·서버 테스트 125개로, 친구 둘이 필요한 상호작용도 혼자 회귀 검증.
- 성능: 대화 기록의 움직이는 그림 수천 개가 각자 애니메이션을 돌려 GPU를 붙잡고 오버레이까지 버벅이던 문제를, 화면에 보이는 것만 공용 루프 하나로 그리게 바꿔 해결.
- 태그 push 한 번으로 Mac·Windows 설치 파일 빌드와 릴리스 노트 공개까지 자동화.

## 결과

① 2026년 11월 1일 공개 뒤 8일 동안 9번 릴리스(v3.6.2), 가입 70명·그룹 38개(11월 9일 기준). Cloudflare Workers 월 $5와 GitHub Releases로 운영.

② 설치부터 캐릭터 제작 가이드까지 처음 보는 사람도 혼자 설치하고 직접 그린 캐릭터로 노는 흐름을 전부 자체 개발.

## 회고

메신저의 핵심이 "메시지"가 아니라 "옆에 있다는 느낌"이라는 걸 만들면서 알았다. 대화창 대신 캐릭터 상태와 장난을 앞에 두었더니 오히려 더 자주 말을 걸게 되었다. 또 상대가 있어야만 확인되는 기능일수록 자동화된 e2e가 없으면 개발 속도가 친구의 시간에 묶인다는 걸 체감했고 테스트를 "혼자 일하기 위한 동료"로 다루게 되었다.
