## 배경 및 목표

사용자가 미래의 다양한 이벤트(정치, 경제, 스포츠 등) 결과에 베팅하고 탈중앙화된 가치 청산을 수행하는 Web3 예측 시장 플랫폼 구축 기획

→ 일반적인 Web3 서비스의 고질적인 문제인 **유저의 매 트랜잭션 가스비 지불 허들**을 제거하기 위해 ERC-4337(계정 추상화)을 과감히 도입. 또한, 실시간으로 쏟아지는 온체인 베팅/정산 이벤트 트래픽이 웹 서버에 직접적인 병목을 주지 않도록 비동기 메시지 큐(AWS SQS) 기반의 분산 인스턴스 환경 설계

## 역할

시스템 구조 설계 참여 및 주도적 개발

## 주요 업무 및 성과

### ① ERC-4337(계정 추상화) 및 SIWE 기반 차세대 Web3 유저 경험(UX) 엔드포인트 설계

- **계정 추상화(AA) 지갑 아키텍처 연동:** 용자가 매번 메타마스크 팝업을 띄우고 직접 가스비를 지불하는 기존 방식에서 탈피, 플랫폼 단에서 스마트 계정을 생성하도록 구현. 사용자는 단 한 번 디지털 서명만 제출하면 가속 및 일괄 처리가 가능해지는 고도화된 Web3 사용자 경험 제공.
- **SIWE(Sign-In with Ethereum) 인증 처리:** 블록체인 지갑 주소를 기반으로 암호학적 검증을 수행하는 SIWE 규격을 준수하여 지갑 기반 세션 및 사용자 인증 아키텍처 표준 확립.

### ② Tracker ➔ SQS ➔ Aggregator 구조의 고가용성 블록체인 이벤트 파이프라인 구축

- **오프체인 미러링의 비동기 결합도 완화:** 블록체인노드에서 실시간으로 발생하는 마켓 생성, 베팅 입금, 결과 정산 등의 이벤트를 트래킹 서비스가 실시간 추적(Polling/Listening)하도록 구현.
- **AWS SQS 기반의 서킷 브레이커 및 댐퍼(Damper) 효과:** 추적된 Raw 데이터를 웹 API 서버에 직접 밀어 넣지 않고 AWS SQS에 적체시킨 뒤, aggregator 마이크로서비스가 자원 여력에 맞춰 비동기 소비 및 배치 가공하도록 설계하여 Base RPC 노드 과부하 및 DB 데드락을 원천 차단.
- **스케줄러 기반 배치 정산 구조화:** 특정 예측 마켓의 마감 시점 및 유저 랭킹 업데이트를 이벤트 드리븐 스케줄러를 통해 주기적으로 배치 제어하는 파이프라인 확립

### ③ 프로토콜 아키텍처의 점진적 고도화 (V1 → V2 → V3 스마트 컨트랙트 설계)

- **[V1] 기초 모델 수립 및 자금 격리 (ERC20 기반):** 예측 시장의 MVP 단계를 구축하며, 예측 자금과 채널/분쟁 담보 자금을 물리적으로 분리하는 트윈 보틀(Two-Vault) 구조를 설계하여 금융 자산의 안정성 확보.
- **[V2] 사용자 경험 개선 (ETH 네이티브 지원):** 사용자가 복잡한 ERC20 토큰 approve 과정 없이 ETH를 직접 payable 함수로 송금해 베팅할 수 있도록 개편. 내부적으로는 WETH(Wrapped ETH)로 자금을 래핑하여 정산 로직의 일관성 유지 및 결과 제안 파이프라인 연동.
- **[V3] 하우스 리스크 관리 및 고정 배당률(Fixed Odds) 도입:** 베팅 총액 내에서만 나눠 갖는 피어 투 피어(P2P) 방식의 한계를 넘어, 베팅 시점에 보상액이 확정되는 고정 배당률 모델 도입. 프로토콜이 감당할 수 있는 최대 손실 임계값을 통제하기 위해 실시간 잔액 모니터링 시스템 이식.
